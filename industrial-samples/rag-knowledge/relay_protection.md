# Релейная защита и автоматика (РЗА)

## Принципы действия защит

### Максимальная токовая защита (МТЗ, ANSI 51)
Защита с обратнозависимой или независимой характеристикой выдержки времени. Реагирует на увеличение тока выше уставки.

**Алгоритм работы:**
1. Ток превышает уставку → Пуск (PICKUP)
2. Отработка характеристики (IDMT или DT) → Отсчёт времени
3. По истечении выдержки → Отключение (TRIP)
4. Формирование команды на выключатель через GOOSE/DO

**Типовые уставки для фидера 10 кВ:**
- I> (ступень 1): 600 А (первичный), характеристика SI, TMS = 0.30
- I>> (ступень 2, ТО): 1200 А, t = 0 с (мгновенная)
- I>>> (ступень 3, ТО): 3000 А, t = 0 с

### Токовая отсечка (ТО, ANSI 50)
Мгновенная защита — отключение без выдержки времени при достижении тока уставки.

### Защита от замыканий на землю (ТЗНП, ANSI 51N/67N)
Реагирует на ток нулевой последовательности I0 = Ia + Ib + Ic.
- В сетях с изолированной нейтралью (10 кВ): I0 обычно малый → уставка 30 А
- Выдержка: 0.5 с

### Автоматическое повторное включение (АПВ, ANSI 79)
После отключения выключателя защитой — автоматическая подача напряжения.
- Количество циклов: 1–3
- Бестоковая пауза (Dead Time): 0.8–1.5 с
- Время восстановления (Reclaim Time): 30–60 с
- Условия блокировки: ручное отключение, работа ДЗ, неуспешное АПВ

### Защита минимального напряжения (ЗМН, ANSI 27)
- Уставка: 80% Uном
- Назначение: отключение нагрузки при снижении напряжения
- Выдержка: 0.5–3.0 с

### Защита максимального напряжения (ЗМН, ANSI 59)
- Уставка: 120% Uном
- Назначение: защита оборудования от перенапряжений

## Sequence of Events (SOE)

Хронологический журнал всех событий защиты с точностью до миллисекунд:
- **Пуск (PICKUP)**: фиксация начала превышения уставки
- **Срабатывание (TRIP)**: формирование команды отключения
- **Отключение выключателя (OPEN)**: подтверждение отключения через блок-контакт
- **АПВ (AR)**: попытка повторного включения
- **Возврат (RESET)**: возврат защиты в исходное состояние

## COMTRADE (IEC 60255-24)

Формат записи осциллограмм аварийных процессов:
- `.cfg` — конфигурационный файл (текстовый): описание каналов, частота дискретизации, временные метки
- `.dat` — файл данных (бинарный или ASCII): отсчёты аналоговых и дискретных каналов
- `.hdr` — заголовок (опционально)
- `.inf` — информационный файл (опционально)

Типичные каналы записи:
- Аналоговые: Ia, Ib, Ic, I0, Ua, Ub, Uc, U0
- Дискретные: TRIP, TRIP_A, TRIP_B, TRIP_C, AR_START, AR_CLOSE, PICKUP_51, PICKUP_50

## Управление через IEC 61850 (SBO)

Select-Before-Operate (SBO) — двухэтапное управление:
1. **SELECT** → Выбор объекта (выключатель) + проверка интерлока
2. **EXECUTE** → Подтверждение + выполнение команды
3. **CANCEL** → Отмена (если не подтверждено в течение таймаута)

Без предварительного SELECT команда EXECUTE отклоняется.
